# 个人图书收藏管理系统 (BookShelf Manager)

云南大学 软件开发综合实践 课堂作业五 自主实践项目（含三大独立研究任务）。

## 项目简介
本项目是一款轻量、现代且用户友好的个人图书收藏与阅读追踪管理系统。项目基于“状态驱动视图”架构模型，涵盖数据的录入校验、分类标记、星级评定、状态修改、实时搜索及本地持久化，并深入实践了事件委托重构、Blob 文件导出及存储超量容错三大进阶特性。

## 核心功能与亮点

### 一、基本要求达成
1. **多字段信息管理**：支持书名、作者、专业分类、个人星级评分（1-5星）、短评心得、阅读状态（在读/已读）6 个维度的信息管理；
2. **表单验证与错误反馈**：对书名与作者必填项进行空格过滤（`trim()`）与非空校验，未填写时在页面优雅呈现红色告警；
3. **添加与删除**：遵循“先改数组、再调 render”原则，支持单条图书数据的快速添加与安全删除；
4. **状态修改与查询检索**：
   - **修改**：提供一键切换【📖 设为在读 / ✅ 标记为已读】状态修改，状态徽章联动变色；
   - **查询**：支持搜索框 `input` 实时多字段模糊搜索，以及专业分类联动筛选；
5. **本地持久化**：采用 `localStorage` 进行全状态存储，结合 `JSON.stringify` 与 `JSON.parse` 成对序列化，刷新浏览器数据不丢失；
6. **XSS 安全防护**：所有用户输入内容在挂载至 DOM 树时，严格使用 `textContent` 赋值，彻底杜绝恶意脚本注入风险。

### 二、三大独立研究任务达成
1. **研究任务一：事件委托（Event Delegation）重构**
   - 将原本每个卡片按钮独立挂载的监听器收拢到父容器 `bookList` 上，利用 DOM 事件冒泡机制，通过 `e.target.dataset.action` 和 `target.closest('.book-card')` 统一派发操作；
   - 显著降低监听器数量与内存开销，彻底解决动态增删元素时的监听器重复绑定或漏绑问题。
2. **研究任务二：数据导出（Blob 与 URL.createObjectURL）**
   - 点击“📥 导出图书数据 (JSON)”按钮，利用原生 JavaScript `Blob` 对象与 `URL.createObjectURL` 动态创建虚拟下载链接，一键将当前收藏列表以格式化 JSON 文件导出至本地。
3. **研究任务三：存储容错研究与故意实验**
   - 深入调查 `localStorage` 的 5MB 配额上限；
   - 在 `save()` 函数中引入 `try...catch` 结构，成功捕获 `QuotaExceededError` 异常，并在界面呈现温和提示；
   - 提供故意实验测试按钮，点击写入 6MB 数据验证容错机制，控制台无未捕获异常，确保系统健壮性。

## 技术栈
- 结构层：HTML5 语义化标签
- 表现层：CSS3 Flexbox 响应式布局
- 行为层：原生 JavaScript (ES6+、DOM 操作、事件委托、localStorage、Blob API)
